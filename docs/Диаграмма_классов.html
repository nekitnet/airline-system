Связи между классами

1. Ассоциация (пунктирная стрелка - - - - - - >)

  • Ticket → Flight - Билет связан с рейсом
  • Ticket → Passenger - Билет связан с пассажиром
  • Ticket → User - Билет связан с пользователем
  • CrewMember → Flight - Член экипажа связан с рейсом
  • CrewMember → Staff - Член экипажа связан с персоналом

2. Агрегация (ромб незакрашенный ◇)

  • Flight ◇→ Ticket - Рейс содержит билеты (агрегация, билет может существовать без рейса)
  • Flight ◇→ CrewMember - Рейс содержит членов экипажа (агрегация)
  • Passenger ◇→ Ticket - Пассажир имеет билеты (агрегация)
  • Staff ◇→ CrewMember - Персонал связан с экипажем (агрегация)
  • User ◇→ Ticket - Пользователь имеет билеты (агрегация)

3. Композиция (ромб закрашенный ◆)

  • User ◆→ Passenger - Пользователь содержит пассажира (композиция 1:1, пассажир не может существовать без пользователя)

Примечания

Эта диаграмма классов построена на основе анализа схемы базы данных Prisma и API-маршрутов системы управления авиарейсами.

Особенности реализации:

  • Класс User представляет пользователей системы (администраторы и пассажиры)
  • Класс Passenger хранит информацию о пассажирах и связан с User отношением композиции
  • Класс Flight представляет авиарейсы с информацией о маршруте, дате, времени и самолете
  • Класс Staff представляет сотрудников авиакомпании (пилоты, стюардессы, инженеры)
  • Класс Ticket связывает пассажиров с рейсами и содержит информацию о месте и статусе оплаты
  • Класс CrewMember является связующей таблицей между Flight и Staff (многие-ко-многим)
