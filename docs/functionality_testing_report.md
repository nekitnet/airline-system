# Отчет о функциональном тестировании системы авиаперелётов

## Введение

Функциональное тестирование — это вид тестирования программного обеспечения, при котором проверяется, соответствует ли система спецификациям функциональных требований. Оно направлено на проверку функций системы с точки зрения конечного пользователя.

Тест-кейс — это документ, который описывает последовательность действий, которые необходимо выполнить для проверки определенной функции или функциональности системы. Каждый тест-кейс включает в себя шаги выполнения, ожидаемый результат и фактический результат.
