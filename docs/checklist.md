# Таблица тест-кейсов для системы авиаперелётов

| Функция/Модуль | Сценарии тестирования |
|----------------|----------------------|
| Регистрация пользователей | а) Успешная регистрация с корректными данными (имя пользователя, пароль, роль) |
| | б) Попытка регистрации с уже существующим именем пользователя |
| | в) Регистрация без заполнения обязательных полей (имя пользователя, пароль, роль) |
| | г) Регистрация с пустым полем имени пользователя |
| | д) Регистрация с пустым полем пароля |
| | е) Регистрация с пустым полем роли |
| | ж) Регистрация с некорректными данными (слишком короткий пароль, недопустимые символы в имени пользователя) |
| Авторизация пользователей | а) Успешный вход с корректными логином и паролем |
| | б) Вход с неверным логином |
| | в) Вход с неверным паролем |
| | г) Вход с пустым логином |
| | д) Вход с пустым паролем |
| | е) Вход с несуществующим пользователем |
| | ж) Проверка доступа к защищённым маршрутам без авторизации |
| Управление рейсами | а) Успешное создание нового рейса с корректными данными (откуда: Минск, куда, дата, время, самолёт) |
| | б) Создание рейса без обязательных полей |
| | в) Создание рейса с пустым полем "откуда" |
| | г) Создание рейса с пустым полем "куда" |
| | д) Создание рейса с пустым полем "дата" |
| | е) Создание рейса с пустым полем "время" |
| | ж) Создание рейса с пустым полем "самолёт" |
| | з) Получение списка всех рейсов |
| | и) Получение рейсов с фильтрацией по дате |
| | к) Проверка корректности сортировки рейсов по дате и времени |
| Управление пассажирами | а) Успешное создание нового пассажира с корректными данными (имя, паспорт, email, телефон, userId) |
| | б) Создание пассажира без заполнения обязательных полей |
| | в) Создание пассажира с уже существующим номером паспорта |
| | г) Создание пассажира с некорректным форматом email |
| | д) Создание пассажира с недопустимыми значениями в поле телефона |
| | е) Проверка привязки пассажира к существующему пользователю (userId) |
| Управление билетами | а) Успешное создание нового билета с корректными данными (рейс, пассажир, место, цена) |
| | б) Создание билета без заполнения обязательных полей |
| | в) Создание билета с уже занятым местом |
| | г) Создание билета с несуществующим рейсом |
| | д) Создание билета с несуществующим пассажиром |
| | е) Получение списка всех билетов |
| | ж) Получение списка билетов для конкретного пользователя |
| | з) Проверка статуса билета (забронирован, оплачен, отменён) |
| Управление персоналом | а) Успешное добавление сотрудника с корректными данными |
| | б) Добавление сотрудника без обязательных полей |
| | в) Назначение сотрудника на рейс |
| | г) Удаление сотрудника с рейса |
| | д) Получение информации о сотруднике по ID |
| | е) Обновление информации о сотруднике |
| Управление бронированиями | а) Создание бронирования для пользователя |
| | б) Отмена бронирования |
| | в) Проверка статуса бронирования |
| | г) Получение списка бронирований для пользователя |
| | д) Проверка возможности изменения бронирования |
| Безопасность | а) Проверка аутентификации при доступе к защищённым API-эндпоинтам |
| | б) Проверка авторизации (пользователь не может получить доступ к данным других пользователей) |
| | в) Защита от SQL-инъекций |
| | г) Защита от XSS-атак |
| | д) Проверка обработки некорректных данных в API-запросах |
| Интеграции | а) Проверка работы API при нормальных условиях |
| | б) Проверка обработки ошибок базы данных |
| | в) Проверка работы при отключённой базе данных |
| | г) Проверка корректности возвращаемых HTTP-статусов |
| | д) Проверка структуры ответов API |
| Производительность | а) Проверка времени отклика API при получении списка рейсов |
| | б) Проверка времени отклика API при создании нового рейса |
| | в) Проверка поведения системы при одновременных запросах |
| | г) Проверка использования ресурсов при нормальной нагрузке |
| Граничные условия | а) Проверка работы с минимальными значениями (например, самая ранняя возможная дата рейса) |
| | б) Проверка работы с максимальными значениями (например, самая поздняя возможная дата рейса) |
| | в) Проверка работы с нулевыми значениями (например, цена билета = 0) |
| | г) Проверка работы с очень длинными строками в текстовых полях |
| | д) Проверка работы с отрицательными значениями там, где они недопустимы |
| | е) Проверка работы с нестандартными символами в текстовых полях |
