# Система Авиакомпания

## Общее описание

Система Авиакомпания - это современное веб-приложение для управления авиакомпанией, позволяющее эффективно управлять рейсами, персоналом, пассажирами и бронированием билетов. Приложение предоставляет удобный интерфейс как для администраторов авиакомпании, так и для пассажиров.

## Основные возможности

- **Управление рейсами**: создание, редактирование и отслеживание статусов рейсов
- **Управление персоналом**: учет сотрудников авиакомпании их назначение на рейсы
- **Управление пассажирами**: регистрация и учет пассажиров
- **Бронирование билетов**: удобная система покупки и управления авиабилетами онлайн
- **Аутентификация и авторизация**: надежная система с разными уровнями доступа
- **Отслеживание статусов**: мониторинг статусов рейсов и билетов в реальном времени

## Стек технологий

- **Frontend**: Next.js 15, React 19
- **UI Framework**: shadcn/ui, Tailwind CSS
- **Backend**: Next.js API Routes
- **База данных**: SQLite (через Prisma ORM)
- **Состояние**: React Hooks
- **Аутентификация**: собственная система аутентификации
- **Сервер**: Node.js (с использованием tsx)

## API-эндпоинты

### Аутентификация
- `POST /api/auth/login` - Вход пользователя
- `POST /api/auth/register` - Регистрация пользователя

### Рейсы
- `GET /api/flights` - Получение списка рейсов
- `POST /api/flights` - Создание нового рейса
- `GET /api/flights/[id]` - Получение информации о конкретном рейсе
- `GET /api/flights/[id]/crew` - Получение экипажа рейса

### Персонал
- `GET /api/staff` - Получение списка сотрудников
- `POST /api/staff` - Создание нового сотрудника
- `GET /api/staff/[id]` - Получение информации о конкретном сотруднике

### Пассажиры
- `POST /api/passengers` - Создание нового пассажира
- `GET /api/passengers/[id]` - Получение информации о пассажире
- `GET /api/passengers/user/[userld]` - Получение пассажира по ID пользователя

### Билеты
- `GET /api/tickets` - Получение списка билетов
- `POST /api/tickets` - Создание нового билета
- `GET /api/tickets/[id]` - Получение информации о конкретном билете
- `GET /api/tickets/passenger/[userld]` - Получение билетов пассажира

## Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone <URL_репозитория>
   cd aeroplane_system
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Настройте переменные окружения**:
   Создайте файл `.env` на основе `.env.example` и укажите необходимые переменные:
   ```
   DATABASE_URL="file:./dev.db"
   ```

4. **Настройте базу данных**:
   ```bash
   npx prisma db push
   # или для миграции
   npx prisma migrate dev
   ```

5. **Запустите приложение**:
   Для разработки:
   ```bash
   npm run dev
   ```
   
   Для запуска сервера:
   ```bash
   npm run dev:server
   ```

Приложение будет доступно по адресу http://localhost:3000

## Компоненты

### Основные компоненты
- `Button` - универсальная кнопка с различными вариантами стилей
- `Card` - карточка для отображения информации
- `Input` - поле ввода
- `Form` - компоненты для создания форм

### Страницы
- `Главная страница` - представление системы, навигация
- `Рейсы` - список доступных рейсов
- `Административная панель` - управление системой
- `Личный кабинет пассажира` - информация о бронированиях
- `Страницы входа/регистрации` - аутентификация пользователей

## База данных

Система использует следующие основные модели данных:

- **User** - пользователи системы (пассажиры и администраторы)
- **Passenger** - информация о пассажирах
- **Flight** - информация о рейсах
- **Staff** - сотрудники авиакомпании
- **CrewMember** - назначение сотрудников на рейсы
- **Ticket** - информация о билетах
