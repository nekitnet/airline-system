## Быстрый старт

- Установите зависимости: `npm install`
- Скопируйте файл `.env.example` → `.env` и при необходимости скорректируйте `DATABASE_URL`
- Подготовьте базу: `npm run db:push`
- Заполните начальными данными: `npm run db:seed`
- Запустите сервер разработки: `npm run dev`

## Полезные команды

- `npm run db:push` — синхронизирует схему Prisma и SQLite
- `npm run db:seed` — полностью очищает и заново заполняет базу (использует `prisma/seed.ts`)
